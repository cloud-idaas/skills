# 上线验收清单

## 本地改造与验证

- [ ] 列出改造的业务入口、客户端、依赖和锁定版本。每个客户端都使用动态 provider。
- [ ] 迁移后扫描完整、阻断项已处理。记录告警复核结果，检查运行配置、镜像和 CI 中的旧静态凭证及注入入口。
- [ ] 语法分析完整，生产客户端的动态绑定和初始化顺序已回读。无法解析的绑定有逐项人工证据。
- [ ] 已按 [构建指引](build.md) 运行目标项目受影响模块的构建、静态检查、类型检查和测试。探针的离线签名、轮转、固定快照反例和刷新失败测试通过。
- [ ] 核对仓库内容和验证产物，真实 AK、Secret、Token 和凭证缓存均未落入改造文件、示例或日志。

## 运行验收

- [ ] 业务进程和探针使用同一平台配置。运行配置检查通过，部署身份、PAM 取证权限和目标角色已确认。
- [ ] 实际 PAM 取证和业务客户端只读请求成功。按实际启用的 OSS、SLS、OpenAPI 场景记录测试环境、角色、请求与脱敏结果。
- [ ] 已授权资源访问成功，使用获准验证的受限资源核实权限拒绝。记录同一进程与客户端跨首批 STS 有效期的后续请求结果。
- [ ] 分别记录文档与本地验证、业务构建、真实请求和真实续期的结果。缺少输入或授权的项标记为未执行。

## 回退

- [ ] 停用旧凭证前按团队流程完成观察。出现问题时恢复上一发布物和经批准的配置，由既有凭证管理流程恢复所需材料，保留权限基线并重新验证应用。
